# Biológia oxidáció (2)
-  Szőlőcukor biológiai oxidációja
	- -> $O_2$  **AEROB**
- Energiát termel => ***ATP** keletkezik*
- 1 mol szőlőcukor => 38 mol ATP
- $C_{6}H_{12}O_{6}$ 
	- => $6CO_2$     *oxidáció*
	- => $6H_2O$     *oxidáció* h
- **H-hordozó molekula**
	- NAD (nukleotid) --> NADH
