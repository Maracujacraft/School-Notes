# Heteroatomot tartalmazó szénvegyületek (1)
## Heteroatom
- Nem C és H atom
- pl.: O, N, halogén atomok
- Funkciós csoport
- **Oxigén tartalmű vegyületek**
	1. Alkoh<u><b>ol</b></u>
		- Funkciós csoport: -OH / hidrox<u><b>il</b></u>
			- $CH_3-CH_2-OH$   *etanol* / *etil-alkohol*
		- Telített C-atomhoz kapcsolódó - OH csoport
			- $CH_2=CH-OH$
			- $CH_3-CH=CH-OH$
			- $CH_3-CH_2-CH_2-OH$
	2. Rendűség
		- $CH_3-CH_2-CH_2-OH$ *propán-1-ol*
	3. Szénlánc szerint
		- Telített: $CH_{3}-CH_{2}-CH_{2}-CH_{2}-CH_{2}-CH_{2}-OH$
			- Hexán-1-ol
		- Telítetlen: $CH_{2}=CH-CH_{2}-CH_{2}-CH_{2}-CH_{2}-OH$
			- hex-5-én-1-ol
		- Aromás:![[1. Drawing 2026-02-23 10.55.43.excalidraw]]
		- Elnevezés
	        1. alap CH neve + ol
	        2. végződés előtt számmal jelöljök a -OH csoport helyét
	        3. Többértékű → di, tri, tetra,… szócska végződés előtt
	        4. Funkciós csoport kapja a legkevesebb számot
    - **Molekulaszerkezet**
        - $CH_3$      -     $OH$ => H-híd
         apoláris     poláris
		- Másodrendű kötőerő: **H-híd** 
			- magas olvadás-, és forráspont
	- **Metanol**: (fagyáspont, moláris tömeg)
		- $CH_3 - OH$ 
		- fp.: 65°C
		- M: 32 ${\frac{g}{mol}}$
	- **Etanol**:
		- $CH_3 - CH_3$
		- fp.: 89°C
		- M: 
	- **Oldhatóság**
		- $C_1$ - $C_3$ – korlátlanul elegyednek
		- $C_5$-ig oldódnak vízben
		 => Antipatikus (alkoholos kivonat/oldat) = tinktúra
		- $C_6$-tól nem oldódnak vízben => apoláris oldószer
	- **Szag**
		- $C_1 - C_3$ édeskés
	- **Kémiai tulajdonság**
		1. Éghető
			- Nagy hőfelszabadulás
			- c > 40$\frac{m}{m}$% alkohol (c=koncentráció)
			- $C_2H_5OH + \frac{7}{2}O_2 \rightarrow 2CO_2 + 3H_2O$   $\triangle_rH <0$ 
	- **Ismertebb alkoholok**
		1. Metanol / metil-alkohol (faszesz) $CH_3 - OH$
		2. Etanol / etil-alkohol
