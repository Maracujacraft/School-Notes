# Oxovegyületek (2)
- Oxovegyületek funkciós csoportja: **oxocsoport**
1. formilcsoport / aldehidcsoport
	- **Láncvégi** szénatomhoz kapcsolódó oxocsoportot aldehideknek nevezzük
2. karbonilcsoport / ketoncsoport
	- **Láncközi** szénatomhoz kapcsolódó oxocsoportot tartalmazó vegyületeket ketonoknak nevezzük
## Aldehidek
### Elnevezése
- **’-al’ végződés**
	- metan**al**, etan**al**, propan**al**
- Fontosabb aldehidek hétköznapi neve:
	- metanal = formaldehid
	- acetaldehid
- **Az oxocsoport helyzetét nem kell számmal megadni**
### Molekulaszerkezete
- A formilcsoport **poláris**, ezért a kis szénatomszámú aldehidek **polárisak**
### Fizikai tulajdonságai
- Formaldehid: gáz
- $C_2$-$C_{11}$ C-számú aldehidek: folyadék
- Kis szénatomszámú aldehidek: kellemetlen, szúrós szag
- $C_8$

| Név                  | Képlet           | Fp. (°C) |
| -------------------- | ---------------- | -------- |
| propán               | $CH_3-CH_2-CH_3$ | – 42 °C  |
| acetaldehid (etanal) | $CH_3-CHO$       | + 20 °C  |
| etanol               | $CH_3-CH_2-OH$   | + 78 °C  |
- Forráspontjuk:
	- A megfelelő szénhidrogéneknél magasabb (dipólus-dipólus kölcsönhatás van a poláris aldehidmolekulák között)
	- A megfelelő alkoholokénál alacsonyabb (Az alkoholok esetében hidrogénkötések alakulnak ki)
- Kis szénatomszámú aldehidek oldódnak vízben
### Kémiai tulajdonságai
- Könnyen oxidálhatók **karbonsavvá** (erélyes redukálószerek)
- Az aldehidek redukciójakor elsőrendű alkoholok képződnek
